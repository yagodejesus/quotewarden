# Changelog

## 0.1.0 — 2026-10-29

- Quote verification (exact, altered, missing) with closest-passage reporting.
- Citation support, miscitation and unknown-source detection for `[n]`, `[n, m]`, `[n-m]` and `[^n]`.
- Number checking with decimal comma/point interpretations; English and Portuguese aware.
- `assert_grounded` for tests; text, JSON and Markdown reports; `quotewarden` CLI.
